# Java Estrutura de Dados

Este repositório foi criado com muito carinho pra te ajudar a entender e praticar estruturas de dados em **Java**, com foco na manipulação usando **Streams API**, listas, mapas, sets e muito mais!

📚 **Objetivo**  
Facilitar o estudo de estruturas de dados e lógica de programação com exercícios comentados, soluções explicadas e desafios práticos. Tudo com exemplos reais e uma pegada bem próxima do dia a dia de quem programa em Java.

---

## O que você vai encontrar aqui:

- ✅ Exercícios com List, Map e Set
- ✅ Uso da Stream API (filter, map, reduce, collect, etc)
- ✅ Comparação entre abordagens imperativas e declarativas
- ✅ Desafios para treinar sua lógica
- ✅ Códigos comentados passo a passo
- ✅ Dicas de boas práticas e legibilidade

---

## Pré-requisitos

- Ter o Java 8 ou superior instalado
- IDE de sua preferência (IntelliJ, VS Code, Eclipse…)
- Vontade de aprender e praticar 🧠

---

## Como usar

1. Clone o repositório:
```bash
git clone https://github.com/nataliatsi/java-estrutura-de-dados.git
```

2. Importe o projeto na sua IDE

3. Navegue pelas pastas e escolha um exercício para começar:
   - `/src/exercicios`
   - `/src/desafios`

4. Rode a classe com o método `main()` e explore os comentários

---

## 📌 Organização dos exercícios

Os arquivos estão organizados por tema. Cada pasta contém:

📄 Arquivo `.java` com o enunciado, a solução e comentários explicativos  
🗒️ Em alguns casos, explicações extras com prints ou comparações com outras abordagens
